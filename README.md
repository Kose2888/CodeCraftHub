# CodeCraftHub

A simple personalized learning platform backend for tracking courses you want to learn. Built with Node.js and Express, storing data in a JSON file — no database or authentication required.

## Project Structure

```text
CodeCraftHub/
├── data/
│   └── courses.json          # Persistent course storage
├── src/
│   ├── server.js             # Entry point — starts Express on a port
│   ├── app.js                # Express app setup (middleware + routes)
│   ├── routes/
│   │   └── courses.js        # Route definitions
│   ├── controllers/
│   │   └── coursesController.js
│   └── utils/
│       ├── fileStore.js      # Read/write JSON file helpers
│       └── validation.js     # Input validation
├── package.json
└── README.md
```

## Setup

1. Install dependencies:

```bash
npm install
```

2. Start the server:

```bash
npm start
```

For development with auto-restart on file changes (Node 18+):

```bash
npm run dev
```

The API runs at `http://localhost:3000` by default. Set a custom port with the `PORT` environment variable.

## API Endpoints

Base path: `/api/courses`

| Method   | Endpoint              | Description              | Success Response |
|----------|-----------------------|--------------------------|------------------|
| `GET`    | `/api/health`         | Health check             | `200` + `{ status: "ok" }` |
| `GET`    | `/api/courses`        | List all courses         | `200` + JSON array |
| `GET`    | `/api/courses/stats`  | Course statistics        | `200` + stats object |
| `GET`    | `/api/courses/:id`    | Get one course by ID     | `200` + course object |
| `POST`   | `/api/courses`        | Create a new course      | `201` + created course |
| `PUT`    | `/api/courses/:id`    | Update a course (full)   | `200` + updated course |
| `DELETE` | `/api/courses/:id`    | Delete a course          | `204` no body |

### Course Object

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "Node.js Fundamentals",
  "description": "Learn Express, REST APIs, and file I/O",
  "targetCompletionDate": "2026-08-01",
  "status": "Not Started",
  "createdAt": "2026-06-10T12:00:00.000Z",
  "updatedAt": "2026-06-10T12:00:00.000Z"
}
```

**Field rules:**

- `name` — required, non-empty string
- `description` — required string (can be empty)
- `targetCompletionDate` — required, `YYYY-MM-DD` format
- `status` — required, one of: `Not Started`, `In Progress`, `Completed`
- `id`, `createdAt`, `updatedAt` — generated by the server

### HTTP Status Codes

| Code | Meaning |
|------|---------|
| `200` | OK |
| `201` | Created |
| `204` | No Content (delete success) |
| `400` | Bad Request (validation failure) |
| `404` | Not Found |
| `500` | Internal Server Error |

## Example Requests

### List all courses

```bash
curl http://localhost:3000/api/courses
```

### Get course statistics

```bash
curl http://localhost:3000/api/courses/stats
```

Example response:

```json
{
  "total": 2,
  "byStatus": {
    "Not Started": 1,
    "In Progress": 1,
    "Completed": 0
  }
}
```

### Create a course

```bash
curl -X POST http://localhost:3000/api/courses \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"Express REST\",\"description\":\"Build APIs\",\"targetCompletionDate\":\"2026-07-01\",\"status\":\"Not Started\"}"
```

On Windows PowerShell:

```powershell
curl -X POST http://localhost:3000/api/courses `
  -H "Content-Type: application/json" `
  -d '{"name":"Express REST","description":"Build APIs","targetCompletionDate":"2026-07-01","status":"Not Started"}'
```

### Get a course by ID

```bash
curl http://localhost:3000/api/courses/<id>
```

### Update a course

```bash
curl -X PUT http://localhost:3000/api/courses/<id> \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"Express REST\",\"description\":\"Build APIs\",\"targetCompletionDate\":\"2026-07-01\",\"status\":\"In Progress\"}"
```

### Delete a course

```bash
curl -X DELETE http://localhost:3000/api/courses/<id>
```

## Data Storage

Courses are stored in `data/courses.json` as a JSON array. The file is read and written on every API request using Node's built-in `fs/promises` module. You can also open and edit the file manually to inspect or tweak data.
